# Gym Management System

A basic Gym Management System website developed as a university assignment using **HTML5 and CSS3**.

## Pages
- **Home:** Introduction to the gym and its services.
- **About Us:** Information about the gym, facilities, and trainers.
- **Membership:** Membership plans, pricing, and benefits.

## Technologies Used
- HTML5
- CSS3

## Getting Started
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
